1. What is Impedance Z?
Opposition to AC current. Like resistance, but for AC. Z = R + jX. Ohm unit.
Z = R + jX - Opposition to ACOpen What is Impedance Z? as OWN MAIN ->
2. R - Resistor
Z = R. Phase = 0 deg. Voltage and current IN PHASE. No lag.
R: Z=R, phi=0 degOpen R - Resistor as OWN MAIN ->
3. C - Capacitor
Xc = 1 / (wC). Z = Xc. Phase = -90 deg. Current LEADS voltage by 90.
C: Xc=1/wC, phi=-90 degOpen C - Capacitor as OWN MAIN ->
4. L - Inductor
XL = wL. Z = XL. Phase = +90 deg. Current LAGS voltage by 90.
L: XL=wL, phi=+90 degOpen L - Inductor as OWN MAIN ->
5. Omega w - Angular Frequency
w = 2 * pi * f. f = frequency Hz. Higher f = higher XL, lower Xc.
w = 2*pi*fOpen Omega w - Angular Frequency as OWN MAIN ->
6. R-C Series
Z = sqrt(R^2 + Xc^2). Phase = Negative, between -90 and 0 deg. Capacitive.
RC: Z=sqrt(R^2+Xc^2), phi negativeOpen R-C Series as OWN MAIN ->
7. R-L Series
Z = sqrt(R^2 + XL^2). Phase = Positive, between 0 and 90 deg. Inductive.
RL: Z=sqrt(R^2+XL^2), phi positiveOpen R-L Series as OWN MAIN ->
8. R-L-C Series
Z = sqrt(R^2 + (XL-Xc)^2). If Xc > XL = negative, if Xc < XL = positive.
RLC: Z=sqrt(R^2+(XL-Xc)^2)Open R-L-C Series as OWN MAIN ->
9. Resonance
When XL = Xc, they cancel! Z = R (minimum). Circuit = pure resistor. Max current!
Resonance: XL=Xc, Z=ROpen Resonance as OWN MAIN ->
10. Pavg - Average Power
Pavg = Irms^2 * R = (Vrms/Z)^2 * R = Vrms*Irms * R/Z = Vrms*Irms*cos(phi)
Pavg = Vrms*Irms*cos(phi)Open Pavg - Average Power as OWN MAIN ->
11. Power Factor cos(phi)
cos(phi) = R/Z. 1 = perfect, 0 = no real power. Capacitor corrects PF.
PF = cos(phi) = R/ZOpen Power Factor cos(phi) as OWN MAIN ->
12. Reactive Power
Q = Vrms*Irms*sin(phi). Power bouncing, not used. Capacitor + Inductor trade it.
Q = Vrms*Irms*sin(phi)Open Reactive Power as OWN MAIN ->
13. Phasor Diagram
R on real axis, XL up, Xc down. Z = vector sum. Angle = phi.
Phasor = Vector DiagramOpen Phasor Diagram as OWN MAIN ->
14. AC vs DC
DC: R only, phi=0 always. AC: R + X, phi changes. Impedance = AC resistance.
DC=R, AC=R+jXOpen AC vs DC as OWN MAIN ->
