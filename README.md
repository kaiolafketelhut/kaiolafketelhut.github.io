## What is OMQ?

OMQ is a book cover project + terminal experiment.

- Infinity eye — always visible, no QR code
- JP / UTC clock — live, top-right, in the terminal style
- Linux terminal aesthetic — monospace, black / white, no clutter
- Contact is human, not harvestable
