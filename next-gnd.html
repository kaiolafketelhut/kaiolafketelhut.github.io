3. Why Need GND?
Voltage = DIFFERENCE. 12V means 12V ABOVE GND. Without GND, 12V means nothing! Like height needs sea level.

4. GND = Return Path
Current goes: Vcc -> Transistor -> RL -> GND -> back to Vcc. GND completes the LOOP. No loop = no current!
