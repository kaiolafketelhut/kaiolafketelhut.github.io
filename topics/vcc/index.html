NeXT VCC MAIN - by OMQ
VCC = +12V - Power Source - Twin of GND
VCC - GND = Your Power!

1. What is VCC?
VCC = Voltage at Collector = + Supply. In your Class B: VCC = +12V. GND = 0V. VCC - GND = 12V!
VCC = + SupplyOpen What is VCC? as OWN MAIN ->
2. VCC VIEW
Top wire in diagram. Battery + -> VCC. All power comes FROM VCC, returns TO GND.
VCC = Top, GND = BottomOpen VCC VIEW as OWN MAIN ->
3. VCC in Class B
Q1 collector -> VCC. Q1 pushes + half wave from VCC. Q2 pulls - half to GND. Push-Pull = VCC + GND!
Push = VCC, Pull = GNDOpen VCC in Class B as OWN MAIN ->
4. VCC vs GND
VCC = +12V, GND = 0V. Signal swings between them! Max swing = VCC - GND = 12V. That's your power!
Swing = VCC - GNDOpen VCC vs GND as OWN MAIN ->
5. Measure VCC
Black probe = GND, Red probe = VCC. Must read +12V. If 0V = battery dead / wire broken!
Black=GND, Red=VCCOpen Measure VCC as OWN MAIN ->
6. Dual Supply
Some amps: +12V VCC, -12V VEE, GND middle. Signal swings +12 to -12 = 24V total! Bigger sound!
Dual = +12 / 0 / -12Open Dual Supply as OWN MAIN ->
7. Decoupling Cap
Cap from VCC to GND = filter. Kills noise on VCC. 100uF + 0.1uF = clean VCC!
Cap = Clean VCCOpen Decoupling Cap as OWN MAIN ->
8. VCC Current
Current leaves VCC, through Q1, RL, to GND. I = V/R. More volume = more VCC current!
I = VCC to GNDOpen VCC Current as OWN MAIN ->
9. VCC Drop
Long wire = VCC drops. 12V at battery, 11V at amp = weak sound. Thick wire = no drop!
Thick Wire = No DropOpen VCC Drop as OWN MAIN ->
10. VCC Symbols
VCC, V+, +12V, VDD - all mean + supply! VDD = FET, VCC = BJT. Same idea!
VCC = VDD = V+Open VCC Symbols as OWN MAIN ->
11. What is VEE?
VEE = - Supply. Opposite of VCC. In Class B with dual supply: Q2 goes to VEE, not GND!
VEE = - SupplyOpen What is VEE? as OWN MAIN ->
12. Power = VCC x I
P = VCC * I. 12V x 1A = 12W. Bigger VCC = bigger power = louder speaker!
P = VCC x IOpen Power = VCC x I as OWN MAIN ->
13. VCC Safety
VCC = live! Don't short VCC to GND = spark + smoke! Always check before power on!
Never Short VCC-GNDOpen VCC Safety as OWN MAIN ->

Open Class B MAIN, find Q1 top wire - follow it - it goes to VCC! That's VCC VIEW!
