# MAIN - IaC - Infrastructure as Code - DEEP DIVE - EAL149 R.259 SONNE

IaC = Infra ist Code, nicht Klick! Server, Netz, DB - alles in Datei!

Klick-Ops vs IaC: Klick = keiner weiss was gebaut wurde. IaC = Code in Git, 100x bauen = 100x gleich, Rollback = Git Revert!

Tools: Terraform / OpenTofu - Cloud-Standard, Pulumi - Python/TS, Ansible - Config YAML, Crossplane - K8s als IaC!

3 Regeln: 1. Alles in Git! 2. Idempotent - 2x laufen = gleich! 3. Immutable - Nicht reparieren, neu bauen!

OMQ: Wenn du es nicht in Code hast, hast du es nicht!
