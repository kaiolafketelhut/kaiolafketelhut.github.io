### Clean Code = Code, den man gern liest!
Computer versteht jeden Code! Mensch nur sauberen Code! Du liest Code 10x öfter als du schreibst!
**Clean Code = In 6 Monaten noch verstehen, ohne Kopfschmerzen!**

### Die 3 Clean-Code-Regeln
| Regel | Schlecht | Gut |
| --- | --- | --- |
| Namen | `x`, `data2`, `tmp` | `eal_nummer`, `user_name` |
| Kurz | Funktion 200 Zeilen! | Funktion 10 Zeilen, 1 Aufgabe! |
| Kein Duplikat | 3x gleicher Code kopiert! | 1x Funktion, 3x aufrufen! DRY! |

### DRY + KISS + YAGNI
| Prinzip | Was? | Merksatz |
| --- | --- | --- |
| DRY | Don't Repeat Yourself! | 1x schreiben, oft nutzen! |
| KISS | Keep It Simple! | Einfach > Clever! |
| YAGNI | You Ain't Gonna Need It! | Bau nur, was jetzt gebraucht wird! |

### OMQ-Beispiel - Dein OMQ ist Clean!
Schlecht: `a=1; b=2; print(a)` - Was ist a? Gut: `eal_nummer=174; print(eal_nummer)` - Sofort klar!

### 3 Fehler vermeiden
1. **Clever statt klar:** `x if y else z if a else b` = Keiner versteht! Klar schreiben!
2. **Kommentar lügt:** Kommentar sagt alt, Code sagt neu! Lieber Code klar, wenig Kommentar!
3. **Riesen-Funktion:** Macht alles = Testet nix! 1 Funktion = 1 Aufgabe!
