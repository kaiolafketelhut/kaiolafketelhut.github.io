Was macht diese Seite?
1. Zeigt, wie MOSFETQ auf NGINX läuft
2. Gibt dir die fertige Config zum Kopieren
3. Verlinkt zurück zu main.html / links.html

1. NGINX Config – kopieren & einfügen

server {
  listen 443 ssl http2;
  server_name kaiolafketelhut.github.io;
  root /var/www/mosfetq;
  index main.html links.html;

  # MOSFETQ + oeneye
  location / {
    try_files $uri $uri.html $uri/ =404;
    add_header X-MOSFETQ "BUILT-IN-BERLIN";
    add_header X-OENEYE "ISMS-v48";
  }

  # Cache für Bilder / CSS
  location ~* \.(css|js|png|jpg)$ {
    expires 30d;
    add_header Cache-Control "public";
  }

  # Sicherheit
  add_header X-Content-Type-Options nosniff;
  add_header X-Frame-Options SAMEORIGIN;
}

2. So testest du es

nginx -t → muss syntax is ok sagen.
systemctl reload nginx → neu laden.
Dann öffnen: https://kaiolafketelhut.github.io/MOSFETQoeneyeNGINX.html
