QEMU CLONE
CLONE VMs IN SECONDS

NeXT QEMU Clone - by OMQ
From https://tinyurl.com/qemu-clone

1. virt-clone - Auto Clone
Clone a VM, auto-generate name + disk
virt-clone --original demo --auto-clone
2. virt-clone - Manual Clone
Clone with your own name + file
virt-clone --original demo --name newdemo --file /var/lib/libvirt/images/newdemo.img
3. Proxmox - qm clone
Clone in Proxmox VE
qm clone 100 101 --name web01 --full
4. Proxmox - Linked Clone
Fast linked clone (no full copy)
qm clone 100 101 --name web01
5. Proxmox - Full Clone qcow2
Full copy, qcow2 format
qm clone 100 101 --full --format qcow2 --storage local-lvm
6. qemu-img - Create Disk
Create 80G qcow2 disk
qemu-img create -f qcow2 haha.img 80G
7. qemu-img - Clone Disk
Clone qcow2 via backing file
qemu-img create -b haha.img -f qcow2 haha01.img
8. qemu-img - Info
Check if disk has backing file
qemu-img info --backing-chain myvm.qcow2
9. qemu-img - Convert to Standalone
Flatten overlay to standalone
qemu-img convert -p -O qcow2 overlay.qcow2 flat.qcow2
10. virt-sysprep - Clean Clone
Clear machine-id + SSH keys in clone
virt-sysprep -a clone.qcow2 --hostname newhost
