1. Sigmoid
0 to 1. S-curve. Old school.
sigmoid = 1/(1+e^-x)Open Sigmoid as OWN MAIN ->
2. Tanh
-1 to 1. Centered sigmoid.
tanh = (e^x-e^-x)/(e^x+e^-x)Open Tanh as OWN MAIN ->
3. ReLU
0 if negative, x if positive. Most used.
relu = max(0,x)Open ReLU as OWN MAIN ->
4. Leaky ReLU
Small slope if negative. Fixes dead ReLU.
leaky = max(0.01x, x)Open Leaky ReLU as OWN MAIN ->
5. ELU
Smooth for negative. Faster learning.
elu = x if x>0 else alpha*(e^x-1)Open ELU as OWN MAIN ->
6. GELU
Gaussian Error Linear Unit. Transformers.
gelu = x * Phi(x)Open GELU as OWN MAIN ->
7. Softmax
Probabilities sum to 1. Last layer.
softmax = e^x / sum(e^x)Open Softmax as OWN MAIN ->
8. Swish
x * sigmoid(x). Google Brain.
swish = x * sigmoid(x)Open Swish as OWN MAIN ->
9. Linear
No activation. y=x. Regression.
linear = xOpen Linear as OWN MAIN ->
10. Step
0 or 1. Perceptron.
step = 1 if x>0 else 0Open Step as OWN MAIN ->
11. PReLU
Learnable leaky slope.
prelu = max(ax, x)Open PReLU as OWN MAIN ->
12. SELU
Self-normalizing. Keeps mean 0 var 1.
selu = lambda * eluOpen SELU as OWN MAIN ->
