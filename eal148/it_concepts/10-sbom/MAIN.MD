# MAIN - SBOM - Software Bill of Materials - DEEP DIVE - EAL148 R.258 MOND

## Was?
SBOM = Zutatenliste fuer Software! Was ist drin? Welche Library? Welche Version?

## Warum?
Log4Shell 2021: Alle wussten - irgendwo ist Log4j drin. Aber WO?
Mit SBOM: In 5 Min wissen - diese 12 Apps sind betroffen, diese nicht!

## Was steht drin?
- Name, Version, Hersteller
- Lizenz - MIT? Apache? GPL?
- Hash - Ist Datei veraendert?
- Abhaengigkeiten - Was haengt wovon ab?

## Formate
- **CycloneDX** - JSON / XML, modern, OWASP
- **SPDX** - ISO Standard, Linux Foundation
- **SWID** - alt, ISO

## Wie erstellen?
- Syft, Trivy, CycloneDX-CLI, Microsoft SBOM Tool
- Bei jedem Build automatisch!

## VEX - Wichtig!
VEX = Vulnerability Exploitability eXchange
Sagt: Ja, Library hat Luecke, aber wir sind NICHT betroffen, weil wir Funktion nicht nutzen!
