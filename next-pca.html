PCA
INTRODUCTION

From High Dimensions to Meaningful Features
NeXT PCA - by OMQ
From @learnwithsudha Reel

PCA (Principal Component Analysis) is a dimensionality reduction technique that transforms high-dimensional data into a smaller set of uncorrelated variables (principal components) while preserving the most important information.
X_new = X W
X : Original data (n x p)
W : Transformation matrix (p x k)
X_new : Reduced data (n x k) - k << p
1. Why Do We Need It?
High-dimensional data is hard to visualize and analyze. Many features are correlated (redundant). Helps reducing noise and improves model performance. Useful for visualization, compression and faster computation.
Key Point: PCA keeps the most important variation in the data.
2. How It Works - 4 Steps
1. Standardize the data (optional, but recommended)
2. Compute covariance matrix (or correlation matrix)
3. Find eigenvalues and eigenvectors (of covariance matrix)
4. Project data onto top k principal components
The first few components capture most of the variation.
3. Visual Example - 2D -> 1D
2D data -> 1D using 1 principal component
Feature 1 + Feature 2 (Original 2 features) -> PCA -> PC1 (After PCA, 1 component)
Same data, just better!
4. Before vs After
Before PCA: Feature 1 vs Feature 2 - scattered
After PCA: PC1 vs PC2 - same data, just better
Same data... Smarter Representation!
5. Real-World Applications
Image Compression (JPEG) • Face Recognition • Data Visualization • Noise Reduction • Feature Engineering (ML)
Used in computer vision, finance, healthcare, marketing and more!
6. Practical Example
A dataset with 1000 features can be reduced to 10-50 principal components without losing much information.
Original Data 1000 features -> PCA -> Reduced Data 10-50 features
Less features = Faster training + Better performance
7. Key Takeaways
✓ PCA reduces dimensionality
✓ It finds the most important patterns
✓ It keeps useful information, removes noise
✓ Great for visualization, compression and ML pipelines
PCA = Less Dimensions -> More Clarity -> Better Decisions
Try PCA in Python - Copy This
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

X_scaled = StandardScaler().fit_transform(X)
pca = PCA(n_components=2)
X_new = pca.fit_transform(X_scaled)
print(pca.explained_variance_ratio_)
