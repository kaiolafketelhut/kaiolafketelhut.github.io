1. What is RAM?
Random Access Memory. Temporary memory. Loses data when power off. CPU works from RAM, not from disk.

2. SRAM - Static RAM
Faster but Expensive. No refresh needed. Uses flip-flops. Cache memory.

3. DRAM - Dynamic RAM
Slower but Cheaper. Needs refresh. Uses capacitor + transistor. Main memory.

4. SDRAM - Sync DRAM
Syncs with System Clock. Faster than DRAM.

5. DDR RAM - Double Data Rate
Faster than SDRAM. Transfers on BOTH edges of clock = 2x.

Faster than DDR. Lower power. 240 pins.
