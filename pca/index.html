1. Mean
Average of each feature. Center of data.
mean = sum(x)/nOpen Mean as OWN MAIN ->
2. Centering
Subtract mean. Data centered at 0.
X_centered = X - meanOpen Centering as OWN MAIN ->
3. Covariance
How features move together.
Cov = (X^T X)/(n-1)Open Covariance as OWN MAIN ->
4. Eigen Decomposition
Find directions of max variance.
Cov * v = lambda * vOpen Eigen Decomposition as OWN MAIN ->
5. Eigenvalues
How much variance in each direction. lambda.
lambda1 > lambda2 > ...Open Eigenvalues as OWN MAIN ->
6. Eigenvectors
The directions. Principal Components.
v1, v2, ... = PCsOpen Eigenvectors as OWN MAIN ->
7. Sorting PCs
Sort by eigenvalue DESC. PC1 = most variance.
PC1 > PC2 > PC3Open Sorting PCs as OWN MAIN ->
8. Projection
Project data onto PCs. Reduce dimensions.
Z = X_centered @ V_kOpen Projection as OWN MAIN ->
9. Variance Explained
How much info kept?
explained = lambda / sum(lambda)Open Variance Explained as OWN MAIN ->
10. Reconstruction
Go back from PCs to original.
X_hat = Z @ V_k^T + meanOpen Reconstruction as OWN MAIN ->
11. SVD
Faster way - Singular Value Decomposition.
X = U S V^TOpen SVD as OWN MAIN ->
12. Standardization
Scale features first if units differ.
z = (x-mean)/stdOpen Standardization as OWN MAIN ->
