1. What is OP-AMP?
OP-AMP = Operational Amplifier. 8-pin chip. 2 inputs (+ -), 1 output. Gain = 100,000x! Uses VCC + VEE + GND!

2. 8 Pins - FAT12
Pin 2 = - IN, Pin 3 = + IN, Pin 6 = OUT, Pin 7 = VCC (+12), Pin 4 = VEE (-12). Pins 1,5,8 = offset / NC.

3. 2 Inputs - + and -
+ IN = non-inverting, - IN = inverting. OUT = (V+ - V-) x Gain. Difference x 100k!
OUT = (V+ - V-) x GainOpen 2 Inputs - + and - as OWN MAIN ->
4. Virtual Ground
- IN = Virtual GND = 0V when + IN = GND. Not connected, but acts like GND! Magic of feedback!

5. Feedback = Control
Without feedback, gain 100k = useless, saturates! With feedback resistor, gain = 1 + Rf/R1. Control!

6. Inverting Amp
Signal to - IN, + IN to GND. Gain = -Rf/R1. Minus = flips signal upside down!
Gain = -Rf/R1Open Inverting Amp as OWN MAIN ->
7. Non-Inverting Amp
Signal to + IN, - IN via feedback. Gain = 1 + Rf/R1. No flip, same phase!
Gain = 1 + Rf/R1Open Non-Inverting Amp as OWN MAIN ->
8. Voltage Follower
OUT to - IN directly. Gain = 1. No gain, but buffer! High IN, Low OUT impedance. Isolator!
Gain = 1, BufferOpen Voltage Follower as OWN MAIN ->
9. Comparator Mode
No feedback! V+ > V- = OUT = VCC (+12). V+ < V- = OUT = VEE (-12). 1-bit ADC!
